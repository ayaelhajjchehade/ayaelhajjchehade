## Featured Projects

### [Online Retail Data Analysis](https://github.com/ayaelhajjchehade/Online_Retail_data_analysis)

An end-to-end analysis of the UCI Online Retail II dataset using MySQL, Python, pandas, and Excel. The project covers data cleaning, sales and returns analysis, customer and product analysis, revenue concentration, country-level trends, and RFM customer segmentation. The results are presented in an interactive Excel dashboard.

**Key finding:** The analysis identified a 1.76% return rate on £19.66 million in gross sales, resulting in £18.93 million in net revenue.

### [HR Attrition Dashboard](https://github.com/ayaelhajjchehade/hr-attrition-analysis)

A business-focused Excel dashboard that uses KPI cards, pivot tables, charts, and slicers to analyze employee attrition and help identify where attrition risk is concentrated.

### [Hotel Bookings SQL Analysis](https://github.com/ayaelhajjchehade/hotel-bookings-analysis)

A SQL-based data-cleaning and exploratory-analysis project using hotel booking data. It examines cancellations, booking patterns, pricing, market segments, lead time, and hotel type. This project demonstrates my practical SQL and data-quality work.
